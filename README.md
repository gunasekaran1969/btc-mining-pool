# BTC Mining Pool Lab

A self-hosted Bitcoin mining pool project for learning Stratum, share accounting,
block submission, and payout workflows.

## Status
Experimental / private deployment.

## Components
- Bitcoin Core node
- Stratum server
- Share validation and worker accounting
- Payout service
- Monitoring dashboard

## Security
Secrets are never committed. Configure them through environment variables or a
secret manager.
